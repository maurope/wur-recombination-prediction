\# PlantRep - Repetitive Element FASTA Files



\*\*Last updated:\*\* 2026-10-14



\## Overview



Unfortunately, the PlantRep database, which provided curated FASTA sequences of repetitive elements for numerous plant species, is no longer available online.



This repository preserves copies of the FASTA files for the following species:



\- \*Brassica oleracea\*

\- \*Solanum lycopersicum\*

\- \*Arabidopsis thaliana\*



The files for \*B. oleracea\* and \*S. lycopersicum\* were downloaded from PlantRep and used for repetitive element annotation in the associated publication. The \*A. thaliana\* file was also downloaded from the database but was not used in the study.



\## Data provenance



The files shared here are exact copies of the files originally obtained from the PlantRep database. They are provided to preserve access to these resources while the original database remains unavailable.



\## Acknowledgments



I hope the PlantRep database will become available again in the future. Until then, I hope these files will be useful to researchers working on repetitive element annotation and related analyses in plant genomes.
